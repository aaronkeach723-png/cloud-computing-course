Cloud computing has become an an important of my daily life i can even say that maybe it's already became a culture for me, 
for the reason that i use a lot of cloud-based applications without realizing it. The most cloud services that I regularly use are Google Drive, Messenger, and Netflix. 
These applications make it easier for me to store files, communicate or talk with others, and enjoy entertainment anytime and anywhere as long as I have an internet connection.

Google drive is an example of Software as a Service (SaaS) because I use it through the internet without having the need to install or manage any servers. 
It is also an example of a Public Cloud because it is available to anyone who creates a Google account. I use Google Drive to store most of my school documents 
or activities and access them from different devices.

Messenger is also a Software as a Service (SaaS) and uses a Public Cloud deployment model. I use Messenger every day so that i can communicate to my classmates, friends, and family. 
Since the application is managed by Meta, I only need an internet connection to send messages, make calls, and share files.

And the last one that i mostly use is netflix, it is also another example again of Software as a Service (SaaS) running on a Public Cloud. It let's me watch movies and TV shows online 
without downloading or managing the software. Everything is provided and maintained by Netflix, making it convenient and easy to use.

Version control is very important when working on cloud projects as it keeps track of changes made to files and allows users to restore previous versions if mistakes happen. 
Git and GitHub help individuals and team in collaborating efficiently by recording every update, making it easier to monitor progress and avoid conflicts. Learning GitHub in this 
course has helped me understand how developers organize projects and work together more effectively in cloud computing.
